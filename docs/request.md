# 프로젝트: "박산 키우기" — 파이썬 슬롯 로그라이크 게임 (파이썬 기말과제)

## 1. 목표
게임 이름: "박산 키우기"
스팀 게임 "SlotBound"처럼 슬롯머신을 돌려 점수를 모으는 간단한 로그라이크 게임을 만든다.
파이썬 수업 기말과제이며 배포용이 아니다. 기능은 최소한으로, 코드는 읽기 쉽게 만든다.
원작의 이름·이미지·사운드는 쓰지 않는다. 그래픽은 직접 만들어서 쓴다
(도형/텍스트/이모지 수준이면 충분).
- 게임 이름 "박산 키우기"를 창 제목, 시작 화면, README, 기획서에 똑같이 쓴다
- "키우기"라는 이름에 맞게, 라운드를 통과할수록 "박산"이 성장하는 느낌을 준다
  (예: 라운드마다 레벨/단계 표시가 바뀜, 시작 화면과 게임 오버 화면에 현재 단계 표시)

## 3. 필수 기술 조건
- 언어: Python 3.11+만 사용 (다른 언어, 웹 기술 사용 금지)
- GUI: tkinter (표준 라이브러리)
- DB: sqlite3 (표준 라이브러리)
- 실행파일: PyInstaller로 Windows용 단일 exe (--onefile --windowed)
- exe 파일 이름: 박산키우기.exe
- 외부 라이브러리는 PyInstaller 말고는 쓰지 않는다
- 공개 저장소이므로 비밀키, 개인정보, 절대경로를 코드에 넣지 않는다

## 4. 게임 규칙 (단순 버전)
- 3x3 슬롯판. "스핀" 버튼을 누르면 각 칸에 심볼이 랜덤으로 나온다
- 심볼마다 점수가 있다 (예: 체리 1, 레몬 2, 종 3, 7 = 5, 다이아 8)
- 가로/세로/대각선으로 같은 심볼 3개가 맞으면 보너스 배수를 준다
- 한 라운드에 스핀은 5번. 라운드가 끝날 때 목표 점수를 넘지 못하면 게임 오버
- 라운드를 통과하면 상점에서 심볼 3개 중 1개를 골라 내 심볼 풀(덱)에 추가한다
  → 덱이 강해지는 로그라이크 요소
- 라운드를 통과할 때마다 박산의 성장 단계가 올라간다 (단계 이름은 4~5개 정도)
- 라운드가 올라갈수록 목표 점수가 증가한다
- 게임 오버가 되면 최종 라운드, 점수, 성장 단계를 DB에 저장한다

## 5. 화면 구성
1) 시작 화면: 게임 제목 "박산 키우기", 플레이어 이름 입력,
   [게임 시작], [랭킹 보기], [종료]
2) 게임 화면: 슬롯판 3x3, 현재 점수/목표 점수/남은 스핀/라운드/박산 성장 단계 표시,
   [스핀] 버튼
   - 스핀할 때 짧게 굴러가는 애니메이션 (tkinter의 after() 사용)
3) 상점 화면: 심볼 3개 중 하나 선택
4) 게임 오버 화면: 최종 점수, 도달한 라운드, 박산 성장 단계 표시
   + "기록이 DB에 저장되었습니다" 안내 문구 + [다시하기] [메인으로]
5) 랭킹 화면: DB에서 상위 10개 기록을 표로 표시 (ttk.Treeview)
   - 열: 순위 / 이름 / 점수 / 라운드 / 성장 단계 / 플레이 날짜

## 6. DB 설계 (sqlite3)
- 파일명: game.db
- 저장 위치: exe 또는 main.py와 같은 폴더
  (주의: PyInstaller onefile은 임시폴더(_MEIPASS)에서 실행되므로,
   sys.frozen일 때는 sys.executable 기준 경로를 쓸 것)
- 처음 실행할 때 테이블이 없으면 자동으로 생성
- 테이블
  - players(id INTEGER PK, name TEXT UNIQUE, created_at TEXT)
  - records(id INTEGER PK, player_id INTEGER FK, round_reached INTEGER,
            score INTEGER, growth_stage TEXT, played_at TEXT)
- SQL은 모두 파라미터 바인딩(?)을 쓴다. 문자열을 이어 붙여 쿼리를 만들지 않는다
- DB 코드는 src/db.py 한 파일에 모은다
- 저장소 루트에 schema.sql을 둔다: CREATE TABLE 문 전체 + 각 컬럼 주석
  (db.py도 이 SQL과 같은 구조로 테이블을 만들어야 한다)

### DB 연동 증명 (교수님이 GitHub에서 확인할 수 있게)
- README에 "DB 연동" 섹션을 만든다 (과제 제출물 바로가기 표 바로 아래):
  1) 사용 DB: SQLite (sqlite3 표준 라이브러리), 파일: game.db (실행 시 자동 생성)
  2) 테이블 구조 표 (players, records) + schema.sql 링크
  3) DB 동작 표:
     | 시점 | 동작 | SQL | 코드 위치 |
     |---|---|---|---|
     | 프로그램 시작 | 테이블 생성 | CREATE TABLE IF NOT EXISTS | db.py 함수 링크 |
     | 게임 시작 | 플레이어 등록/조회 | INSERT / SELECT | db.py 함수 링크 |
     | 게임 오버 | 기록 저장 | INSERT | db.py 함수 링크 |
     | 랭킹 화면 | 상위 10개 조회 | SELECT ... ORDER BY ... LIMIT 10 | db.py 함수 링크 |
     → 코드 위치는 GitHub 줄 번호 링크(#L10-L25 형식)로 건다
  4) 스크린샷 2장 (images/ 폴더):
     - images/ranking.png : 게임 안 랭킹 화면 (기록이 여러 개 쌓인 상태)
     - images/db_browser.png : DB Browser for SQLite로 game.db를 연 화면
     (스크린샷은 내가 직접 찍어서 넣을 테니, 자리와 파일명만 정해 두고
      찍는 방법을 나에게 단계별로 안내해줘)
- 기획서.md의 "6) DB 설계"에도 같은 표와 schema.sql 링크를 넣는다
- 줄 번호 링크는 코드가 바뀌면 어긋나므로, 마지막 커밋 후에 다시 확인해서 맞춘다

- 오늘 범위: 기획서 초안 OK + 추가 기능 반영 + 구현 계획 제안까지. 사장 OK 전 코드 작성 금지.

   - 최산: 검정·젖은 질감·이마와 한쪽 눈 위로 흐르는 앞머리 2~3가닥 / 귀 거의 안 보임 / 굵은 직선 눈썹·바깥 끝 살짝 올라감 / 가로로 길고 가는 눈·눈꼬리 위·작은 눈동자 / 갸름한 V라인·날렵한 턱 / 곧고 짧은 코 / 얇은 일자 입(무표정) / 밝은 살구색 피부
