# 테스트 목록 (3단계, 사장 승인 대기)
"이것들이 다 되면 끝". **자동** = pytest가 확인, **사장** = 사장이 화면이나 캡처로 확인.
테스트 코드는 사장 OK 뒤에 `tests/`에 쓰고, 먼저 전부 실패하는 것을 확인한 뒤 구현한다.
