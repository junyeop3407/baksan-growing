# 명세서 (Claude 작업 기준, 사장 검토 대상 아님)
기획서와 다르면 기획서(사장 확정본)가 우선이다. 바뀌면 둘 다 고친다.

## 한 줄 / 사용자
- 파이썬 기말과제 슬롯 로그라이크 "박산 키우기". 사용자: 사장(백준엽)과 채점하는 교수님. Windows PC, 마우스.

## 규칙 (숫자)
- 총알: 연습탄1, 보통탄2, 예광탄3, 철갑탄5, 황금탄8. 처음 덱 [연습4, 보통3, 예광2, 철갑1] (황금은 상점만).
- 스핀: 9칸 각각 덱에서 균등 무작위(중복 허용, 개수만큼 확률). 줄 8개(가로3, 세로3, 대각2).
- 스핀 점수 = 9칸 합 × (1 + 맞은 줄 수). 한 칸이 여러 줄에 속해도 줄마다 셈. 9칸 모두 같으면 8줄 → ×9.
- 라운드: 스핀 5번, 라운드 점수 0부터. 목표 = floor(100 × 1.25^(라운드-1)) → 100,125,156,195,244,305…. 점수 ≥ 목표면 통과(같으면 통과).
- 총점 = 모든 라운드 점수 합(실패한 라운드 점수 포함). DB score = 총점.
- 계급: 통과 수 0 이병, 1 일병, 2 상병, 3 병장, 4 이상 하사. 최산 비율 0, .25, .5, .75, 1.0.
- 상점: 5종 중 서로 다른 3개 무작위, 1개 선택 → 덱에 1개 추가. 이미 있는 종류도 가능.
- 게임 오버 기록: name, round_reached(실패한 라운드 번호), score(총점), growth_stage(계급 이름), played_at.

## 화면
- 시작: 제목, 이병 캐릭터, 이름 입력(strip 후 1~10글자, 아니면 안내 문구, 시작 안 함), [게임 시작][랭킹 보기][종료]
- 게임: 왼쪽 3x3(칸 ≥ 80px, 총알 그림+이름), 오른쪽 캐릭터(계급장·말풍선), 상단 정보, [스핀]. 스핀 애니메이션 약 0.6초 동안 버튼 막힘.
- 통과: 진급 → 춤 약 3초 + "난 최산을 닮았다" (스핀 막힘) → 상점 → 다음 라운드 + "난 섹시해.... ㅋ"
- 게임 오버 화면: 캐릭터 + "she's so BAD...", 점수/라운드/계급, "기록이 DB에 저장되었습니다", [다시하기]: 같은 이름으로 [메인으로]
- 랭킹: Treeview 상위 10 (순위/이름/점수/라운드/계급/플레이 날짜). 정렬 score desc, round_reached desc, played_at asc(같으면 id asc). 0개면 빈 표 + "아직 기록이 없습니다".
- 배경: 연병장 + 막사 Canvas. 창 최소 크기 고정(잘림 방지).
- 말풍선 약 2.5초, 새 것이 오면 앞의 것 즉시 삭제, 캐릭터 Canvas 안에만.
- 줄 맞음 강조: 칸 테두리 두꺼운 노란 선(그림 안 가림).

## 캐릭터
- 성재/최산 설정값 dict 두 개, t로 보간(숫자 선형, 색 RGB, 모양 점 좌표, 있다/없다 길이·진하기). t=0/1에서 원본과 정확히 같아야 함.
- 부위 태그 분리: body, arm_l, arm_r, head, badge, bubble. 춤은 after()로, 예약 id 보관 → 창 닫기·화면 전환 시 모두 취소. 춤 중 새 춤 시작 안 함.

## DB
- game.db: frozen이면 sys.executable 폴더, 아니면 main.py 폴더(= src/). 처음 실행 시 CREATE TABLE IF NOT EXISTS.
- players(id PK, name TEXT UNIQUE NOT NULL, created_at TEXT NOT NULL), records(id PK, player_id FK, round_reached, score, growth_stage, played_at). 모든 SQL ? 바인딩. schema.sql과 같은 구조.

## 정한 것
- 제출 저장소 따로(이 작업장 이름 변경 후 새 공개 baksan-growing). 테스트는 작업장에만(pytest).
- 성장 단계 = 군대 계급(하사 = 4라운드 통과). 심볼 = 총알 5종(이모지 안 씀, 이모지는 Tk 9에서 흑백 윤곽선이었음).
- 목표 100×1.25 (1000판 시뮬레이션 하사 도달 17~37%).
- 창 최소 크기로 잘림 방지, 게임 오버 말풍선은 게임 오버 화면 캐릭터 위 (사장 OK).
- 성재 이름·캐릭터 공개 저장소 사용: 본인 확인 완료(사장, 2026-11-18).
- draw_bullet은 symbols.py (tkinter import 없이 받은 Canvas에 그림).

## 아직 안 정한 것
