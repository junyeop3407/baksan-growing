# 배운 것과 미룬 것

## 미룬 것
- clean_name: 폭 0 공백(U+200B) 같은 보이지 않는 글자만 있는 이름도 1글자로 통과한다. 키보드로 넣기 어려워 미룸 (리뷰 1단계).
- E1(가장 작은 창에서 칸 80px 이상): 창 최소 크기는 ui.py가 정하므로 ui 단계에서 테스트를 쓴다.
- C4 화면 부분("빈 표 + 아직 기록이 없습니다"): ui 단계.

## 배운 것
- 테스트를 먼저 쓸 때는 머리 주석만 있는 빈 모듈을 먼저 만들어야 테스트가 import 오류 한 번이 아니라 하나하나 실패한다.
- export_submission.py는 git이 추적하는 파일만 복사한다. 그래서 작업장에서 먼저 커밋한 뒤에 돌려야 한다(커밋 안 한 변경이 있으면 멈춤).
- Windows Git Bash에서 파이썬 출력이 깨지면 `PYTHONIOENCODING=utf-8`을 붙인다.
